# KinetikHub 1.2.0

**Install and update from GitHub.** A new **Updates…** window lists every Kinetik app, and Hub itself, against its latest GitHub release: **Install** apps that aren't on this PC, **Update** one or **Update all**, open **Versions…** for release notes and to install any release (including going back), and **Skip** a version. **Install updates automatically** keeps the companion apps current without asking; the bar and Hub still ask. Hub can now update itself. Downloads are checked against GitHub's SHA-256 digest before anything is replaced, as before. The tray menu offers the pending updates, and the update balloon opens the Updates window. When GitHub's hourly limit for checks without signing in is reached, Hub says so and when it resets.
